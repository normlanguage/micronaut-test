# Micronaut Test

[English](README.md) | [简体中文](README.zh-CN.md)

[`micronaut.test`](micronaut/test/module.norm) combines Micronaut Test and JUnit Jupiter. [`module.norm`](micronaut/test/module.norm) is the single source for public dependencies. [Samples](samples/README.md) exercise dependency injection and bean replacement in a separate consumer module.
